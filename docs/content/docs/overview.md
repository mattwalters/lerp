# Overview

Lerp is one binary and one screen. `lerp init` wires a repository to a Linear
team; running `lerp` opens the board that moves the work across it. There is
no server and no store of lerp's own.

The manual around this page is still being written. Until it is, the pages
under Reference are it: [the README](/README.md) is the working manual, and
[SCOPE.md](/SCOPE.md) is the fence the project is built inside.
