# Overview

Lerp is one binary and one screen. `lerp init` wires a repository to a Linear
team; running `lerp` opens the board that moves the work across it. There is
no server and no store of lerp's own: Linear holds every durable fact, and
lerp reconciles the coding agents running on this machine against it.

The manual around this page is still being written. Until it is,
[the README](/README.md) is it — installing, wiring a repo to a team, running
the loop, the stock pipeline, and what to do when something looks stuck — and
[SCOPE.md](/SCOPE.md) is the fence around the project: five concepts, nine
invariants, and the litmus tests every change runs through.
